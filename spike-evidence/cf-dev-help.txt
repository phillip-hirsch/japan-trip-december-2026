cf dev [implArgs..]

Run the project's Cloudflare dev server

Positionals
  implArgs  Arguments forwarded to the dev-server implementation
                                                           [array] [default: []]

Global flags
  -q, --quiet       Suppress non-essential output     [boolean] [default: false]
  -z, --zone        Zone ID or domain name (overrides CLOUDFLARE_ZONE_ID)
                                                                        [string]
      --profile     Use a specific auth profile                         [string]
  -m, --mode        Mode used to evaluate project configuration         [string]
      --local       Use local resource simulations    [boolean] [default: false]
      --persist-to  Directory holding local persisted state (default:
                    ~/.config/cloudflare/state)                         [string]
  -h, --help        Show help                                          [boolean]
  -v, --version     Show version number                                [boolean]

Options
      --dry-run  Parse arguments and show the command without executing it
                                                      [boolean] [default: false]

cf dev starts the appropriate development server for your project. It runs your
framework's dev command when available, falling back to an installed Cloudflare
dev server.

Only --mode is forwarded to supported framework development servers. Other
arguments are forwarded only to Cloudflare dev-server implementations.
